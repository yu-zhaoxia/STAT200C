1 Statistical Inference in Linear Models

Throughout this section we assume \[ Y=X\beta+\epsilon, \qquad \epsilon\sim N(0,\sigma^2I_n), \] where \(X\) is an \(n\times p\) design matrix with full column rank.

Statistical inference in linear models includes many useful statistical tools. We have covered estimation and optimality of least squares estimates. In this section, we will cover the following topics: hypothesis testing / model comparison, confidence intervals /bands, and predictions.

2 Hypothesis Testing

We focus primarily on hypothesis testing for linear constraints of the form \[ H_0: A\beta=c \quad \text{v.s.} \quad H_1: A\beta \neq c \]

A hypothesis \(A\beta=c\) is testable if each row of \(A\beta\) represents an estimable function of \(\beta\). Suppose \(dim(A)=q\times p\), we assume \(Rank(A)=q<p\).

The following tests will be covered:

  • F-Test

  • likelihood ratio test

  • Wald test

  • score test

2.1 F-Test

Theorem 1  

  1. Restricted and Full Model RSS Relationship
\[\begin{aligned} &RSS_H-RSS = RSS_{reduce}-RSS_{full}=\|\hat{Y}-\hat{Y}_H\|^2 \\ &= (A\hat{\beta}-c)^T[A(X^TX)^{-1}A^T]^{-1}(A\hat{\beta}-c)=Z^TB^{-1}Z \end{aligned}\]

where \(Z\sim N(A\beta-c,\sigma^2B)\).

  1. Expected value of \(RSS_H-RSS\): \[E[RSS_H-RSS]= \sigma^2q+(A\beta-c)^T[A(X^TX)^{-1}A^T]^{-1}(A\beta-c)\]

  2. F-statistic for testing \(H_0: A\beta=c\):

\[\begin{eqnarray*} F &=& \frac{(RSS_H-RSS)/q}{RSS/(n-p)}\\ &=& \frac{(A\hat{\beta}-c)^T[A(XX^T)^{-1}A^T]^{-1}(A\hat{\beta}-c)}{qS^2}\overset{H_0}\sim F_{q,n-p}. \end{eqnarray*}\]

  1. Projection Matrix Representation:

When \(c=0\), \(F\) can be expressed in the form \[ F=\frac{n-p}{q}\frac{Y^T(P_X-P_H)Y}{Y^T(I-P_X)Y} \] where \(P_H\) is symmetric and idempotent, and \(P_HP_X=P_XP_H=P_H\).

The matrix \(P_H\) is the projection matrix onto the restricted model space \[ \{X\beta:A\beta=0\}. \]

Proof. Proof for a \[\begin{eqnarray*} RSS_H=\epsilon^T\epsilon &=& ||Y-\hat{Y}_H||^2\\ &=& ||Y-\hat{Y}+\hat{Y}-\hat{Y}_H||^2\\ &=& ||Y-\hat{Y}||^2 + ||\hat{Y}-\hat{Y}_H||^2 + 2(Y-\hat{Y})^T(\hat{Y}-\hat{Y}_H)\\ &=& ||Y-\hat{Y}||^2 + ||\hat{Y}-\hat{Y}_H||^2 + 2Y^T(I-P_X)X(\hat{\beta}-\hat{\beta}_H)\\ &=& ||Y-\hat{Y}||^2 + ||\hat{Y}-\hat{Y}_H||^2 + 2Y^T(X-X)(\hat{\beta}-\hat{\beta}_H)\\ &=& ||Y-\hat{Y}||^2 + ||\hat{Y}-\hat{Y}_H||^2 \\ &=& RSS + \| X(\hat{\beta}-\hat{\beta}_H) \|^2 \end{eqnarray*}\] Thus, \[\begin{eqnarray*} RSS_H - RSS &=& \|X(\hat{\beta}-\hat{\beta}_H)\|^2\\ &=& (A\hat{\beta}-c)^T[A(X^TX)^{-1}A^T]^{-1}(A\hat{\beta}-c) \end{eqnarray*}\]

Proof for b

Because \(\hat{\beta}\sim N_p(\beta, \sigma^2 (X^TX)^{-1})\) and the rows of \(A\) are linearly independent (\(dim(A)=q\times p\) and \(Rank(A)=q<p\), we have \[A\hat{\beta} \sim N_q(A\beta, \sigma^2 A(X^TX)^{-1}A^T ).\] Let \(Z=A\hat{\beta}-c\), we have \[Z\sim N(A\beta-c, \sigma^2B),\] where \(B=A(X^TX)^{-1}A^T\). Thus \[\begin{eqnarray*} E[RSS_H-RSS] &=& E[Z^TB^{-1}Z]\\ &=& tr(\sigma^2B^{-1}B) + (A\beta-c)^TB^{-1}(A\beta-c)\\ &=& \sigma^2q + (A\beta-c)^TB^{-1}(A\beta-c) \end{eqnarray*}\] [Recall that \(Y\sim N(\mu,\Sigma)\), then \(E[Y^TAY]=tr(A\Sigma)+\mu^TA\mu\).]

Proof for c First \(RSS/\sigma^2\sim \chi_{n-p}^2\). This is true as \[\begin{eqnarray*} \frac{RSS}{\sigma^2} &=& \frac{(Y-X\hat\beta)^T(Y-X\hat\beta)}{\sigma^2}\\ &=& \frac{((I-P_X)Y)^T((I-P_X)Y)}{\sigma^2}\\ &=& \frac{(Y-X\beta)^T(I-P_X)(Y-X\beta)}{\sigma^2} \sim \chi_{n-p}^2 \end{eqnarray*}\] The last equation is true because \[(I-P_X)Y=(I-P_X)Y-(I-P_X)X\beta=(I-P_X)(Y-X\beta).\]

Under the null hypothesis \(Z\sim N(0, \sigma^2B)\). \[ \frac{RSS_H-RSS}{\sigma^2}=\frac{Z^T B^{-1} Z}{\sigma^2}\sim \chi_q^2 \] We have also shown that \(RSS/\sigma^2\sim \chi_{n-p}^2\).

One more thing we need to show is that \(RSS_H-RSS\) and \(RSS\) and independent. Notice that \(RSS=||(I-P_X)Y||^2\) and \(RSS_H-RSS=Z^TB^{-1}Z\), where \(Z=A\hat \beta -c = A (X^TX)^{-1}X^TY -c\). So it is sufficient to show the following

\[\begin{aligned} cov((I-P_X)Y, Z) &= cov((I-P_X)Y, A\hat\beta)\\ &= cov((I-P_X)Y, A(X^TX)^{-1}X^TY)\\ &=(I-P_X)\sigma^2\mathbf I X (X^TX)^{-1} A^T\\ &=0 \end{aligned}\]

The last step is true because \((I-P_X)X=X-P_XX=X-X=\mathbf 0\).

Proof for d When \(c=0\), \[\begin{eqnarray*} \hat{Y}_H &=& X\hat{\beta}_H\\ &=& {P_X- X(X^TX)^{-1}A^T[A(X^TX)^{-1}A^T]^{-1}A(X^TX)^{-1}X^T } Y\\ &=& (P_X-P_1)Y\\ &=& P_H Y \end{eqnarray*}\] It is easy to show that \(P_1\) is symmetric and idempotent, and \(P_1P_X=P_XP_1=P_1\), which implies that \(P_H\) is symmetric and idempotent, and \(P_HP_X=P_H\) and \(P_XP_H=P_H\). \[\begin{eqnarray*} RSS_H &=& \|Y-X\hat{\beta}_H\|^2\\ &=& Y^T(I_n-P_H)^2Y\\ &=& Y^T(I_n-P_H)Y \end{eqnarray*}\] Therefore, \(RSS_H-RSS=Y^T(P_X-P_H)Y\)

Summary:

  • \(RSS/\sigma^2 \sim \chi_{n-p}^2\) and \(E[RSS]=(n-p)\sigma^2\).

  • F-statistic: \[F=\frac{(RSS_H-RSS)/q}{RSS/(n-p)}=\frac{(A\hat\beta -c )^T[A (X^TX)^{-1}A^T]^{-1}(A\hat\beta -c)}{\hat\sigma^2}\]

  • \(F\overset{H_0}\sim F_{q,n-p}\).

  • Multiple R-squared and F:

    • Multiple R-squared for the full model: \(R^2=1-RSS/SSTO\).
    • Multiple R-squared for the reduced model: \(R_H^2=1-RSS_H/SSTO\).
    • F-statistic can be expressed as \[F=\frac{(R_H^2-R^2)/q}{(1-R_H^2)/(n-p)}\]

  • We proved the case when both \(X\) and \(A\) are full rank. It can shown that the theorem also applies when they are not full rank. If you can show that \(X\hat\beta_H\) is invariant to the choice of the generalized inverse, all the proof works.

2.2 Likelihood Ratio Test

The likelihood ratio test is based on both the restricted and unrestricted estimators. The likelihood function is \[ L(\beta, \sigma^2) = (2\pi\sigma^2)^{-n/2}exp[-\frac{1}{2\sigma^2}\|Y-X\beta\|^2]\]

The MLEs are \(\hat{\beta}=(X^TX)^{-1}X^TY\) and \(\hat{\sigma}^2=\|Y-X\hat{\beta}\|^2/n=RSS/n\). The maximum value is \[L(\hat{\beta},\hat{\sigma}^2)=(2\pi\hat{\sigma}^2)^{-n/2}e^{-n/2}\]

Under the null hypothesis, \(\beta\) satisfies the constraint \(A\beta=c\). We have shown that \[\hat{\beta}_H=\hat{\beta}+(X^TX)^{-1}A^{T}[A(X^TX)^{-1}A^T]^{-1}(c-A\hat{\beta})\] It is easy to find that \[\hat{\sigma}_H^2=\|Y-X\hat{\beta}_H\|^2/n=RSS_H/n\] The corresponding maximum value of likelihood under the constraint is \[ L(\hat{\beta}_H, \hat{\sigma}_H^2) = (2\pi\hat{\sigma}_H^2)^{-n/2}e^{-n/2}\] The likelihood ratio test statistic is given by \[ \Lambda = \frac{L(\hat{\beta}_H, \hat{\sigma}_H^2)}{L(\beta, \hat{\sigma}^2)} = (\frac{\hat{\sigma}^2}{\hat{\sigma}_H^2})^{n/2} \] According to logic of likelihood ratio, we reject \(H_0\) for small value of \(\Lambda\). One can based on the asymptotic property of \(\Lambda\), i.e., under the null hypothesis \[-2log(\lambda)\dot{\sim} \chi_{q}^2\] to test the hypothesis. Here \(q\) is the difference in number of parameters between the full and the restricted models: there are \(p+1\) parameters in \(H_0\) and \(p+1-q\) parameters in \(H_1\).

With the normality assumption, we can construct exact test: an F-test \[F=\frac{n-p}{q}(\Lambda^{-2/n}-1),\] and \(H_0\) will be rejected when \(F\) is large. More details will be given in next section.

Relation of the F-test to likelihood ratio test

Because \(\hat{\sigma}_H^2=RSS_H/n\) and \(\hat{\sigma}^2=RSS/n\), \[\begin{eqnarray*} F &=& \frac{n-p}{q}\frac{\hat{\sigma}_H^2-\hat{\sigma}^2}{\hat{\sigma}^2}\\ &=& \frac{n-p}{q}(\hat{\sigma}_H^2/\hat{\sigma}^2-1)\\ &=& \frac{n-p}{q}(\Lambda^{-2/n}-1). \end{eqnarray*}\]

Remarks: We know that \(qF_{q,n-p}\) and \(-2log(\Lambda)\) converge to \(\chi_q^2\mbox{ as } n\rightarrow \infty\). The following shows that the likelihood ratio test statistic is identical to \(qF\) by using the first order Taylor approximation: \[-2log(\Lambda)=nlog(\Lambda^{-2/n})=nlog[1+(\Lambda^{-2/n}-1)]\approx n(\Lambda^{-2/n}-1)\approx qF.\]

2.3 Wald Test

The Wald test is based on the unrestricted estimator. When the sample size is large, \((\hat{\beta}-\beta)^T[cov(\hat{\beta})]^{-1}(\hat{\beta}-\beta)\) is roughly \(\chi^2\) and the d.f.=p. Now consider the transformation \(A\hat\beta\). Under the null hypothesis, it has mean \(c\) and covariance \(A cov(\hat\beta) A^T\). Thus, the Wald test is: \[(A\hat\beta-c)^T[A cov(\hat\beta) A^T]^{-1}(A\hat\beta-c)=(A\hat\beta-c)^T[\sigma^2 A(X^TX)^{-1}A^T]^{-1}(A\hat\beta-c)\] Note that the MLEs \(\hat\sigma^2=RSS/n\) and \(\hat\sigma_H^2=RSS_H/n\). If we place \(\sigma^2\) with \(\hat\sigma^2\), the Wald test statsitic becomes \[n(RSS_H-RSS)/RSS=n(\frac{\hat\sigma_H^2}{\hat\sigma^2}-1)=n(\Lambda^{-2/n}-1)\]

It is known that LRT and the Wald and asymptotically equivalent.

2.4 Score Test

The score test is based on the restricted estimator. We omit the results. If there is no nuisance parameter, i.e., \(\sigma^2\) is known, it can be shown that LR=Wald=Score. This is not true because the log-likelihood is quadratic.

Let \((y_1,\cdots,y_n)\) drawn from \(N(\mu,\sigma^2)\) with unknown \(\sigma^2\). The three test statistics for \(H_0:\mu=1\) vs \(H_1:\mu\not=1\) are respectively: \[LR=nlog\left[\frac{\sum (y_i-1)^2}{\sum (y_i-\bar y)^2}\right] \mbox{ , } W=\frac{n^2 (\bar y-1)^2}{\sum (y_i-\bar y)^2} \mbox{ , } S=\frac{n^2 (\bar y-1)^2}{\sum (y_i-1)^2} \]

2.5 Examples

2.5.1 Example 1: Two-Sample t-test

Two-sample t-test with equal variance. Consider \(U_i\overset{iid}\sim N(\mu_1,\sigma^2), i=1,\cdots,m\) and \(V_i\overset{iid}\sim N(\mu_2,\sigma^2), i=1,\cdots,n\). Suppose the two samples are independent. We want to derive a test statistic for \(H_0: \mu_1=\mu_2\).

We use the linear model to describe the distributions: \[Y=X\beta+\epsilon\] where \(Y=(U_1,\cdots,U_m,V_1,\cdots,V_n)^T\) and \[X=\begin{pmatrix} 1&0\\ 1&0\\ \cdots&\\ 1&0\\ 0&1\\ 0&1\\ \cdots&\\ 0&1 \end{pmatrix} \] And \(\beta=(\mu_1,\mu_2)^T\). The null hypothesis becomes \(H_0: (1, -1)\beta=0\).

\[X^TX=\begin{pmatrix} m&0\\ 0&n \end{pmatrix} \]

\[X^TY=\begin{pmatrix} U_+\\ V_+ \end{pmatrix} \]

So we have \[\begin{eqnarray*} \hat \beta &=& (X^TX)^{-1}X^TY= \begin{pmatrix}\bar{U} \\ \bar{V}\end{pmatrix}\\ A\hat\beta &=& \bar{U}-\bar{V}\\ RSS &=& (Y-X\hat\beta)^T(Y-X\hat\beta)=\sum(U_i-\bar(U))^2 + \sum (V_i-\bar{V})^2 \end{eqnarray*}\] The last equation is true because \[Y-X\hat\beta=\begin{pmatrix} U_1-\bar{U}\\ \cdots\\ U_m-\bar{U}\\ V_1-\bar{V}\\ \cdots\\ V_n-\bar{V} \end{pmatrix} \] Also, \(A(X^TX)^{-1}A^T=\frac{1}{m}+\frac{1}{n}\) The F statistic is \[F=\frac{(A\hat\beta-c)^T[A(X^TX)^{-1}A^T]^{-1}(A\hat\beta-c)}{qS^2}=\frac{(\bar U-\bar V)^2}{S^2 (1/m+1/n)} \] Here \(n=m+n-2\), \(q=1\), \(p=2\). Under \(H_0\), \(F\sim F_{1,m+n-2}\). Note, \(t^2=F\).

Method 2 \[\begin{aligned} RSS&=\sum_{i=1}^m(U_i -\bar U)^2 + \sum_{i=1}^n (V_i -\bar V)^2\\ RSS_H &= \sum_{i=1}^m(U_i -\frac{m\bar U + n \bar V}{m+n})^2 + \sum_{i=1}^n (V_i -\frac{m\bar U + n \bar V}{m+n})^2 \end{aligned}\]

The F-test statistic is \[F=\frac{(RSS_H-RSS)/1}{RSS/(m+n-2)}.\]

After some algebra, we can show that the two methods give the same test statistic.

2.5.2 Example 2: One-Way ANOVA

Consider the one-way ANOVA model \[ Y_{ij} = \mu_i + \varepsilon_{ij}, \qquad i=1,\dots,I,\quad j=1,\dots,n_i, \] where \[ \varepsilon_{ij} \overset{\text{iid}}{\sim} N(0,\sigma^2). \]

The factor has \(I\) levels.

We test \[ H_0:\mu_1=\mu_2=\cdots=\mu_I. \]

Define \[ \bar Y_{i\cdot}=\frac1{n_i}\sum_{j=1}^{n_i}Y_{ij}, \qquad \bar Y_{\cdot\cdot}=\frac1n\sum_{i=1}^I\sum_{j=1}^{n_i}Y_{ij}, \] where \[ n=\sum_{i=1}^I n_i. \]

The least squares estimator is \[ \hat\mu_i=\bar Y_{i\cdot}. \]

The residual sum of squares for the full model is \[ RSS = \sum_{i=1}^I\sum_{j=1}^{n_i} (Y_{ij}-\bar Y_{i\cdot})^2. \]

The reduced model under \(H_0\) is \[ Y_{ij}=\mu+\varepsilon_{ij}, \] with \[ \hat\mu=\bar Y_{\cdot\cdot}. \]

The residual sum of squares for the reduced model is \[ RSS_H = \sum_{i=1}^I\sum_{j=1}^{n_i} (Y_{ij}-\bar Y_{\cdot\cdot})^2. \]

Hence \[ RSS_H-RSS = \sum_{i=1}^I n_i (\bar Y_{i\cdot}-\bar Y_{\cdot\cdot})^2. \]

Define \[ SSB = \sum_{i=1}^I n_i (\bar Y_{i\cdot}-\bar Y_{\cdot\cdot})^2 \] and \[ SSW = \sum_{i=1}^I\sum_{j=1}^{n_i} (Y_{ij}-\bar Y_{i\cdot})^2. \]

Then \[ SSTO = SSB + SSW. \]

The ANOVA F-statistic is \[ F = \frac{SSB/(I-1)}{SSW/(n-I)} \sim F_{I-1,n-I} \quad \text{under } H_0. \]

2.5.3 Example 3: Two-Way ANOVA (Balanced Design)

Consider the balanced two-way ANOVA model \[ Y_{ijk} = \mu+\alpha_i+\beta_j+\gamma_{ij}+\varepsilon_{ijk}, \] where \[ i=1,\dots,I, \qquad j=1,\dots,J, \qquad k=1,\dots,K, \] and \[ \varepsilon_{ijk} \overset{\text{iid}}{\sim} N(0,\sigma^2). \]

Interpretation of parameters:

  • \(\mu\): grand mean
  • \(\alpha_i\): main effect of factor A
  • \(\beta_j\): main effect of factor B
  • \(\gamma_{ij}\): interaction effect

Identifiability constraints: \[ \sum_{i=1}^I \alpha_i = 0, \qquad \sum_{j=1}^J \beta_j = 0, \]

\[ \sum_{i=1}^I \gamma_{ij}=0, \qquad \sum_{j=1}^J \gamma_{ij}=0. \]

Hypotheses:

Main effect of A: \[ H_{0A}:\alpha_1=\cdots=\alpha_I=0. \]

Main effect of B: \[ H_{0B}:\beta_1=\cdots=\beta_J=0. \]

Interaction: \[ H_{0AB}:\gamma_{ij}=0 \quad \text{for all } i,j. \]

Define means: \[ \bar Y_{i\cdot\cdot} = \frac1{JK}\sum_{j=1}^J\sum_{k=1}^K Y_{ijk}, \]

\[ \bar Y_{\cdot j\cdot} = \frac1{IK}\sum_{i=1}^I\sum_{k=1}^K Y_{ijk}, \]

\[ \bar Y_{ij\cdot} = \frac1K\sum_{k=1}^K Y_{ijk}, \]

\[ \bar Y_{\cdot\cdot\cdot} = \frac1{IJK}\sum_{i,j,k}Y_{ijk}. \]

Sums of squares:

\[ SSA = JK\sum_{i=1}^I (\bar Y_{i\cdot\cdot}-\bar Y_{\cdot\cdot\cdot})^2, \]

\[ SSB = IK\sum_{j=1}^J (\bar Y_{\cdot j\cdot}-\bar Y_{\cdot\cdot\cdot})^2, \]

\[ SSAB = K\sum_{i=1}^I\sum_{j=1}^J (\bar Y_{ij\cdot} -\bar Y_{i\cdot\cdot} -\bar Y_{\cdot j\cdot} +\bar Y_{\cdot\cdot\cdot})^2, \]

\[ SSW = \sum_{i,j,k} (Y_{ijk}-\bar Y_{ij\cdot})^2. \]

The total sum of squares decomposes as \[ SSTO = SSA+SSB+SSAB+SSW. \]

Under normality, \[ SSA,\quad SSB,\quad SSAB,\quad SSW \] are mutually independent, and \[ \frac{SSA}{\sigma^2}\sim\chi^2_{I-1}, \qquad \frac{SSB}{\sigma^2}\sim\chi^2_{J-1}, \]

\[ \frac{SSAB}{\sigma^2} \sim \chi^2_{(I-1)(J-1)}, \qquad \frac{SSW}{\sigma^2} \sim \chi^2_{IJ(K-1)}. \]

Corresponding F-tests:

\[ F_A = \frac{SSA/(I-1)}{SSW/[IJ(K-1)]}, \]

\[ F_B = \frac{SSB/(J-1)}{SSW/[IJ(K-1)]}, \]

\[ F_{AB} = \frac{SSAB/[(I-1)(J-1)]}{SSW/[IJ(K-1)]}. \]

2.5.3.1 Independence of Sums of Squares

Consider the balanced two-way ANOVA model \[Y_{ijk}=\mu+\alpha_i+\beta_j+\gamma_{ij}+\varepsilon_{ijk},\] where \[i=1,\dots,I,\qquad j=1,\dots,J,\qquad k=1,\dots,K,\] and \[\varepsilon_{ijk}\overset{\text{iid}}{\sim}N(0,\sigma^2).\]

Assume the identifiability constraints \[\sum_{i=1}^I \alpha_i=0,\qquad \sum_{j=1}^J \beta_j=0,\] and \[\sum_{i=1}^I \gamma_{ij}=0,\qquad \sum_{j=1}^J \gamma_{ij}=0.\]

Define the sample means \[\bar Y_{ij\cdot}=\frac1K\sum_{k=1}^K Y_{ijk},\]

\[\bar Y_{i\cdot\cdot}=\frac1J\sum_{j=1}^J \bar Y_{ij\cdot},\]

\[\bar Y_{\cdot j\cdot}=\frac1I\sum_{i=1}^I \bar Y_{ij\cdot},\]

\[\bar Y_{\cdot\cdot\cdot}=\frac1{IJ}\sum_{i,j}\bar Y_{ij\cdot}.\]

The least squares estimators are \[\hat\mu=\bar Y_{\cdot\cdot\cdot},\]

\[\hat\alpha_i=\bar Y_{i\cdot\cdot}-\bar Y_{\cdot\cdot\cdot},\]

\[\hat\beta_j=\bar Y_{\cdot j\cdot}-\bar Y_{\cdot\cdot\cdot},\]

\[\hat\gamma_{ij}=\bar Y_{ij\cdot}-\bar Y_{i\cdot\cdot}-\bar Y_{\cdot j\cdot}+\bar Y_{\cdot\cdot\cdot}.\]

Hence the fitted value is \[\hat Y_{ijk}=\hat\mu+\hat\alpha_i+\hat\beta_j+\hat\gamma_{ij}=\bar Y_{ij\cdot}.\]

Therefore, \[Y_{ijk}=m+a_i+b_j+(ab)_{ij}+e_{ijk},\] where \[m=\bar Y_{\cdot\cdot\cdot},\]

\[a_i=\bar Y_{i\cdot\cdot}-\bar Y_{\cdot\cdot\cdot},\]

\[b_j=\bar Y_{\cdot j\cdot}-\bar Y_{\cdot\cdot\cdot},\]

\[(ab)_{ij}=\bar Y_{ij\cdot}-\bar Y_{i\cdot\cdot}-\bar Y_{\cdot j\cdot}+\bar Y_{\cdot\cdot\cdot},\]

\[e_{ijk}=Y_{ijk}-\bar Y_{ij\cdot}.\]

Since the observations are jointly normal, the vectors \[ (a_1,\dots,a_I) \quad \text{and} \quad (b_1,\dots,b_J) \] are jointly normal. Therefore, it suffices to show \[ \operatorname{Cov}(a_i,b_j)=0 \] for all \(i,j\).

Now \[ \operatorname{Cov}(a_i,b_j) = \operatorname{Cov} (\bar Y_{i\cdot\cdot}-\bar Y_{\cdot\cdot\cdot}, \bar Y_{\cdot j\cdot}-\bar Y_{\cdot\cdot\cdot}). \]

Expanding, \[ \begin{aligned} \operatorname{Cov}(a_i,b_j) &= \operatorname{Cov}(\bar Y_{i\cdot\cdot},\bar Y_{\cdot j\cdot}) -\operatorname{Cov}(\bar Y_{i\cdot\cdot},\bar Y_{\cdot\cdot\cdot}) \\ &\quad -\operatorname{Cov}(\bar Y_{\cdot\cdot\cdot},\bar Y_{\cdot j\cdot}) +\operatorname{Var}(\bar Y_{\cdot\cdot\cdot}). \end{aligned} \]

Because the design is balanced, \[ \operatorname{Var}(\bar Y_{i\cdot\cdot}) = \frac{\sigma^2}{JK}, \qquad \operatorname{Var}(\bar Y_{\cdot j\cdot}) = \frac{\sigma^2}{IK}, \] and \[ \operatorname{Var}(\bar Y_{\cdot\cdot\cdot}) = \frac{\sigma^2}{IJK}. \]

Also, \[ \operatorname{Cov}(\bar Y_{i\cdot\cdot},\bar Y_{\cdot j\cdot}) = \frac{\sigma^2}{IJK}, \] since the two averages share exactly the \(K\) observations \[ Y_{ij1},\dots,Y_{ijK}. \]

Similarly, \[ \operatorname{Cov}(\bar Y_{i\cdot\cdot},\bar Y_{\cdot\cdot\cdot}) = \frac{\sigma^2}{IJK}, \] and \[ \operatorname{Cov}(\bar Y_{\cdot j\cdot},\bar Y_{\cdot\cdot\cdot}) = \frac{\sigma^2}{IJK}. \]

Therefore, \[ \operatorname{Cov}(a_i,b_j) = \frac{\sigma^2}{IJK} -\frac{\sigma^2}{IJK} -\frac{\sigma^2}{IJK} +\frac{\sigma^2}{IJK} =0. \]

Hence the A-effects and B-effects are jointly normal and uncorrelated, so they are independent.

Consequently, \[ SSA = JK\sum_i a_i^2 \] and \[ SSB = IK\sum_j b_j^2 \] are independent quadratic forms.

2.5.3.2 Orthogonality via the Design Matrix

Consider the balanced two-way ANOVA model \[ Y_{ijk} = \mu+\alpha_i+\beta_j+\gamma_{ij}+\varepsilon_{ijk}, \] with \[ i=1,\dots,I, \qquad j=1,\dots,J, \qquad k=1,\dots,K. \]

Write the model as \[ Y=X\theta+\varepsilon, \] where \[ X= \begin{pmatrix} 1 & X_A & X_B & X_{AB} \end{pmatrix}. \]

Here:

  • \(1\): intercept column,
  • \(X_A\): columns for factor A,
  • \(X_B\): columns for factor B,
  • \(X_{AB}\): interaction columns.

Assume sum-to-zero coding is used, so each column of \(X_A\), \(X_B\), and \(X_{AB}\) has mean zero.

2.5.3.2.1 Orthogonality of the Main-Effect Design Matrices

Let \(x_a\) be a column of \(X_A\), and let \(x_b\) be a column of \(X_B\).

Because the design is balanced:

  • each level of factor A occurs equally often within every level of factor B,
  • each level of factor B occurs equally often within every level of factor A.

Hence the positive and negative entries of \(x_a\) average out within each level of B.

Therefore, \[ x_a^T x_b = 0. \]

Thus, \[ X_A^T X_B = 0. \]

Similarly, \[ X_A^T X_{AB}=0, \qquad X_B^T X_{AB}=0. \]

Hence the column spaces \[ \mathcal C(X_A), \qquad \mathcal C(X_B), \qquad \mathcal C(X_{AB}) \] are mutually orthogonal.

2.5.3.2.2 Orthogonal Projection Matrices

Define the projection matrices \[ P_A = X_A(X_A^TX_A)^{-1}X_A^T, \]

\[ P_B = X_B(X_B^TX_B)^{-1}X_B^T. \]

Since \[ X_A^TX_B=0, \] we obtain \[ P_AP_B = X_A(X_A^TX_A)^{-1} (X_A^TX_B) (X_B^TX_B)^{-1}X_B^T =0. \]

Therefore the projections are orthogonal.

2.5.3.2.3 Independence of the Sums of Squares

The sums of squares can be written as \[ SSA = Y^TP_AY, \qquad SSB = Y^TP_BY. \]

Under normality, \[ Y\sim N(X\theta,\sigma^2I). \]

A standard theorem states:

If \(P_1\) and \(P_2\) are symmetric idempotent matrices satisfying \[ P_1P_2=0, \] then \[ Y^TP_1Y \quad \text{and} \quad Y^TP_2Y \] are independent quadratic forms.

Since \[ P_AP_B=0, \] it follows that \[ SSA \perp SSB. \]

Similarly, \[ SSA,\quad SSB,\quad SSAB,\quad SSW \] are mutually independent.

2.5.3.2.4 Important Remark

This orthogonality relies crucially on the balanced design.

For unbalanced data, \[ X_A^TX_B \neq 0 \] in general, so the main-effect spaces are no longer orthogonal.

Consequently:

  • sums of squares depend on the order in which terms are entered,
  • Type I, II, and III sums of squares differ,
  • the clean ANOVA decomposition breaks down.

2.5.3.3 Sum-of-Squares Decomposition

Since all components are orthogonal, \[\sum_{i,j,k}(Y_{ijk}-\bar Y_{\cdot\cdot\cdot})^2\] equals the sum of squared norms of the orthogonal pieces: \[SSTO = SSA + SSB + SSAB + SSW,\] where \[SSA=JK\sum_i a_i^2,\]

\[SSB=IK\sum_j b_j^2,\]

\[SSAB=K\sum_{i,j}(ab)_{ij}^2,\]

\[SSW=\sum_{i,j,k} e_{ijk}^2.\]

This is exactly the ANOVA decomposition from a linear algebra viewpoint.

2.5.3.4 Degrees of Freedom

2.5.4 Example 4: Compare \(K\) Straight Lines

\[Y_{ki}=\alpha_k + \beta_k x_i + \varepsilon_{ki},\] where \(k=1,\cdots,K\), \(i=1,\cdots,n_k\), and \(\epsilon_{ki} \overset{iid}\sim N(0, \sigma^2)\). We want to test

  1. \[H_{01}: \alpha_1=\cdots=\alpha_K\]

  2. \[H_{02}: \beta_1=\cdots=\beta_K\]

  3. \[H_{03}: \alpha_1=\cdots=\alpha_K, \beta_1=\cdots=\beta_K\]

Full Model:

Let \(\mathbf \beta=(\alpha_1, \cdots, \alpha_K, \beta_1, \cdots, \beta_K)^T\). We can write the model in a matrix form \(Y=X\mathbf \beta +\epsilon\). The design matrix \(X\) is \[\begin{pmatrix} \mathbf 1&0&\cdots&0&x_1&0&\cdots&0\\ 0&\mathbf 1&\cdots&0&0&x_2&\cdots&0\\ \cdots&\cdots&\cdots&\cdots&\cdots&\cdots&\cdots&\cdots\\ 0&0&\cdots&\mathbf 1&0&0&\cdots&x_K\\ \end{pmatrix} \]

2.5.4.1 Reduced Models:

  • For \(H_{01}\), the design matrix is \[\begin{pmatrix} \mathbf 1&x_1\\ \mathbf 1&x_2\\ \cdots&\cdots\\ \mathbf 1&x_K\\ \end{pmatrix}\]

  • For \(H_{02}\), the design matrix is \[\begin{pmatrix} \mathbf 1&0&\cdots&0\\ 0&\mathbf 1&\cdots&0\\ \cdots&\cdots&\cdots&\cdots\\ 0&0&\cdots&\mathbf 1\\ \end{pmatrix}\]

  • For \(H_{03}\), the design matrix is \[\begin{pmatrix} \mathbf 1&x_1\\ \mathbf 1&x_2\\ \cdots&\cdots\\ \mathbf 1&x_K\\ \end{pmatrix}\]

2.5.4.2 F-tests

  • For \(H_{01}\), the F-test statistic is \[F_1=\frac{(RSS_{H_{01}}-RSS)/K}{RSS/(n-2K)}\]
  • For \(H_{02}\), the F-test statistic is \[F_2=\frac{(RSS_{H_{02}}-RSS)/K}{RSS/(n-2K)}\]
  • For \(H_{03}\), the F-test statistic is \[F_3=\frac{(RSS_{H_{03}}-RSS)/2K}{RSS/(n-2K)}\]
